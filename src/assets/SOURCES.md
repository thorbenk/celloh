# SVG assets

- `mic.svg`, `mic_off.svg`, `speed.svg`, `music_note.svg`, `settings.svg`, `info.svg`, `help_outline.svg`: Google Material Icons, downloaded individually from `https://fonts.gstatic.com/s/i/materialicons/{name}/v6/24px.svg`. Apache 2.0; license included in `material-icons-LICENSE.txt`.

- `terminal.svg`: Google Material Icons, from `https://raw.githubusercontent.com/google/material-design-icons/master/src/action/terminal/materialicons/24px.svg`, Apache 2.0 (same included license).
- `delete.svg`, `replace_audio.svg`, `fit_page.svg`, `fit_width.svg`, `view_real_size.svg`, `undo.svg`, `chevron_left.svg`, `chevron_right.svg`: Google Material Symbols Outlined, from `https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/{name}/materialsymbolsoutlined/{name}_24px.svg`, Apache 2.0 (same included license).
- Music notation is rendered by [VexFlow](https://github.com/vexflow/vexflow), MIT licensed (see `vexflow-LICENSE.txt`), using its bundled Bravura SVG paths. [Bravura](https://github.com/steinbergmedia/bravura) is SIL Open Font License 1.1; license included in `bravura-LICENSE.txt`. The renderer needs no external font requests and works offline.
