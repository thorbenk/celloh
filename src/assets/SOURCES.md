# SVG assets

- `mic.svg`, `mic_off.svg`, `speed.svg`, `music_note.svg`, `settings.svg`, `info.svg`, `help_outline.svg`: Google Material Icons, downloaded individually from `https://fonts.gstatic.com/s/i/materialicons/{name}/v6/24px.svg`. Apache 2.0; license included in `material-icons-LICENSE.txt`.
- `bass-clef.svg`: based on [Bass clef.svg by Tlusťa on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Bass_clef.svg), public domain. The clef path was extracted, the existing staff lines removed, and the view box cropped for use with the app's staff.

- `terminal.svg`: Google Material Icons, from `https://raw.githubusercontent.com/google/material-design-icons/master/src/action/terminal/materialicons/24px.svg`, Apache 2.0 (same included license).
- `fit_page.svg`, `fit_width.svg`, `view_real_size.svg`, `undo.svg`, `chevron_left.svg`, `chevron_right.svg`: Google Material Symbols Outlined, from `https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/{name}/materialsymbolsoutlined/{name}_24px.svg`, Apache 2.0 (same included license).
- `music-glyphs.ts`: SVG outlines and stem anchors extracted from [Bravura](https://github.com/steinbergmedia/bravura/tree/37b194378b710cc40e406ab6c4b07608bb9548ae), SIL Open Font License 1.1; license included in `bravura-LICENSE.txt`. Regenerate with `uv run scripts/extract-note-glyphs.py` after `npm ci`. The script pins both the source revision and FontTools version; extend its `GLYPHS` list to add symbols such as rests. The generated data uses SVG coordinates at 20 units per staff space and does not require loading a font in the browser.
